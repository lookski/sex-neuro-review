## Method notes

- **Search**: PubMed E-utils (esearch/efetch). Every statistic in the reports is quoted
  verbatim from the verified abstract — no hand-typed numbers, no recall from memory.
- **Impact factors**: LetPub 2025 JCR impact factors (June 2026 release), checked journal
  by journal; journals not indexed get "—" instead of a guess.
- **Reference numbering**: Part 1 = 1–40, Part 2 = 1–23, Part 3 = 1–38; each part has its
  own independent reference table.
- Part 3 includes a **measurement-definition appendix** (Frederick's frequency scale vs
  Herbenick's single-event categorization vs the FSFI cutoff-based prevalence): numbers
  that differ wildly between studies often differ because the question differs. Read it
  before cross-study comparison.
- Inferences that go beyond what an abstract literally says are flagged as
  "模型性陈述" (model statement) in the text.
