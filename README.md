## 方法说明 / Method notes

- 检索: PubMed E-utils (esearch/efetch), 全部引用的数字均照抄摘要原文, 未做任何人工改写或"凭印象"填写。
- Searched via PubMed E-utils; every number in the reports is quoted verbatim from the verified abstract — no hand-typed statistics.
- 期刊 IF 为 LetPub 2025 影响因子 (2026-06 更新版), 逐刊实查; 未进 JCR 的刊标注 "—" 而不是猜数。
- 引用编号规则: 主报告 1–40, 续篇 1–23, 两份报告各自独立成表。
