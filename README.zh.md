## 方法说明 / Method notes

- 检索: PubMed E-utils (esearch/efetch), 全部引用的数字均照抄摘要原文, 未做任何人工改写或"凭印象"填写。
- Searched via PubMed E-utils; every number in the reports is quoted verbatim from the verified abstract — no hand-typed statistics.
- 期刊 IF 为 LetPub 2025 影响因子 (2026-06 更新版), 逐刊实查; 丛书或无独立 JCR 条目者按 LetPub 页面原值标注并加脚注, 不猜数。
- 引用编号规则: 主报告 1–40, 续篇 1–23, 第三篇 1–38, 第四篇 1–19, 第五篇 1–21, 第六篇 1–50, 各自独立成表。
- 第三篇含一个"测量口径对照"附录 (Frederick 频率口径 vs Herbenick 单次事件口径 vs FSFI 量表口径), 跨研究比较前建议先看它。
- 综合推断 (摘要里没有直接原话的) 在报告中一律标 "模型性陈述"。
